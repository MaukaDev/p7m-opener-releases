# P7M Opener

App desktop per macOS e Windows per aprire, verificare ed esportare documenti con firma digitale `.p7m` (CAdES).
Desktop app for macOS and Windows to open, verify and export digitally signed `.p7m` (CAdES) documents.

## Italiano

### Installazione

- **macOS**: apri il `.dmg` e trascina **P7M Opener** in Applicazioni. Al primo avvio fai tasto destro sull'app → **Apri** (l'app non è notarizzata da Apple).
- **Windows**: esegui `P7MOpenerSetup.exe`. Se compare Windows SmartScreen, scegli **Ulteriori informazioni → Esegui comunque**.

### Aggiornamenti

All'avvio l'app controlla se esiste una nuova versione e mostra **"Aggiorna a x.y.z"** in alto. Il controllo si può disattivare dalle Impostazioni. Per aggiornare scarica il nuovo pacchetto e installalo sopra quello esistente.

### Segnalazioni

Hai trovato un problema o hai un suggerimento? Apri una [segnalazione](https://github.com/MaukaDev/p7m-opener-releases/issues).

## English

### Installation

- **macOS**: open the `.dmg` and drag **P7M Opener** into Applications. On first launch, right-click the app → **Open** (the app isn't notarized by Apple).
- **Windows**: run `P7MOpenerSetup.exe`. If Windows SmartScreen appears, choose **More info → Run anyway**.

### Updates

At startup the app checks for a new version and shows **"Update to x.y.z"** at the top. The check can be turned off in Settings. To update, download the new package and install it over the existing one.
